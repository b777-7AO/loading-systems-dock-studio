# Loading Systems · Dock Studio

Concept site and 3D loading-bay configurator for Loading Systems (Dock Equipment, Industrial Doors & Service).

- `konfigurator.html`: Three.js warehouse with up to six docks. Doors (PowerDoor 601, Dock Door 040/045, 620NG, 640PR, fire roller, strip curtain), dock levellers (swing lip, telescopic, stepped, Combidock, manual), dock shelters (curtain, cushion, foam, inflatable, inflatable top, van), bumpers, vehicle restraints, dock lights, traffic lights, interior lights, mandoor. Docking sequence: truck arrives, restraint engages, door opens, shelter seals, leveller rises and lip extends onto the bed.
- `preise.html`: list prices from the price lists 11DE-601N (14.09.2026), 11DE-601DD, 11DE-604NG, 11DE-0620NG (01.06.2026).
- `assets/js/cfg/catalog.js`: product data, options, price engine. `prices.js` is generated from the PDFs.
- `medien.html`: LinkedIn pages and websites per country.

Textures: Poly Haven (CC0). Photos: Loading Systems asset library. Three.js r170.
